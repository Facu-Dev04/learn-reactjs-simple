## Que es una interfas? 

- La interfas son reglas, es una estructura que nosotros le ponemos, la estructura del objeto tiene un tipo de estructura, esto nos sirve para saber tambien con presicion que cosa tenemos que poner.

### Ejemplo

```typescript
export interface PropmtUser {
    name: string
    lastname: string
    age: number
    develoment: boolean
    jobsDev : () => void
}
```
